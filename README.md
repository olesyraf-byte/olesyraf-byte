## Featured Project

### E-commerce Conversion Funnel Analysis

An end-to-end analytics project using SQL, Google BigQuery, and Power BI to explore online shopping behavior and identify conversion bottlenecks.

**Key findings:**
- 49,951 product views
- 12,020 add-to-cart events
- 2,302 purchases
- 75.94% decrease between product views and cart additions
- 4.61% purchase-to-view ratio

**Business recommendation:** Investigate product-page usability and test improvements to add-to-cart interactions.
